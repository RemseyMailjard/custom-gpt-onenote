Builder's guide

Build your own OneNote GPT

A complete, from-scratch walkthrough for ChatGPT Plus/Team/Enterprise users: create the GPT, write its instructions, wire up the OneNote Action, and configure OAuth — using the values below.

Before you start, you need:
  • A ChatGPT Plus, Team, or Enterprise plan (Actions aren't available on the free plan)
  • The Client ID and Client Secret for this app — request the secret from your admin, it's not published on this page
  • 10 minutes
1

Create a new GPT

In ChatGPT, go to Explore GPTs → Create (top right). Skip the chat-based builder and switch straight to the Configure tab — it's faster to fill in directly.

2

Name and describe it

Under Name and Description, enter something a teammate would recognize at a glance:

OneNote Assistant
Reads and writes your OneNote notebooks — search pages, create notes, and update content in plain language.
3

Write the Instructions

Paste the model instructions into the Instructions field on the Configure tab. The full text — ready to copy — is in its own section below: jump to Custom Instructions ↓.

4

Add the Action

Scroll to Actions → Create new action. Under Schema, delete the placeholder text and paste the full OpenAPI schema — also in its own section below: jump to OpenAPI Schema ↓.

Field 1 of 2

Custom Instructions

Goes in the GPT's Instructions field on the Configure tab. It defines what the Action can do and how the model should behave — adjust tone or add house rules freely.

You are OneNote Assistant, a helper that reads, writes and organizes the signed-in user's Microsoft OneNote through the connected Action.

Capabilities:
- List notebooks, sections, section groups, and pages — with optional $filter, $orderby, $expand, and includePreview=true for a short text snippet per result.
- Search pages by title or content.
- Read a page's content as HTML or as clean Markdown (getPageContent?format=markdown — prefer Markdown when just reading or summarizing; use HTML when you'll need element data-ids for an update).
- Create a notebook, section, section group, or a new page from HTML (the <title> becomes the page title).
- Update an existing page by appending, inserting, prepending, replacing, or deleting content.
- Add an image or file attachment to an existing page.
- Copy a page, a whole section, or an entire notebook to another location; move a page to another section.
- Delete a page.

Notes:
- Notebooks and sections cannot be renamed or deleted — Microsoft Graph doesn't support it. Tell the user to do that directly in OneNote.
- Never invent notebook, section, or page names or IDs — always resolve them first via the list operations.

6

Save — and register your callback URL

Click Save in the top right. ChatGPT will now show a Callback URL in the Authentication panel, shaped like:

https://chat.openai.com/aip/g-<your-gpt-id>/oauth/callback
This step is required before sign-in will work Every GPT gets a unique callback URL. It has to be added to the Azure app registration's redirect URIs before anyone can sign in — including you, when you test it. Copy that URL and send it to your admin to whitelist; it's a one-line addition on their end.
7

Test the Action

Back in the Configure tab, click Test next to any operation (e.g. listNotebooks). ChatGPT will prompt you to sign in with Microsoft — use your work or school account. Once you approve, the test call should return your notebooks as JSON.

If sign-in fails with a redirect error, your callback URL from step 6 hasn't been whitelisted yet.

8

Add a privacy policy link

What this app can access

The Action requests exactly two Microsoft Graph permissions — nothing beyond OneNote:

  • Notes.ReadWriteRead and create/edit pages, sections and notebooks in the signed-in user's OneNote — only theirs, never anyone else's.
  • offline_accessKeeps the user signed in between conversations, so they don't have to reauthorize every time.

It cannot read email, calendar, files, or any other Microsoft 365 data — Graph permissions are granted individually per app. Every request runs as the signed-in user's own token, so one person's GPT can never see another person's notebooks.

Common questions
Do I need my own Azure app registration?

No. Everyone building a GPT against this Action reuses the same Client ID and Client Secret above — only the callback URL differs per GPT, and that's what needs whitelisting in step 6.

Can I duplicate someone else's GPT instead of building from scratch?

Duplicating copies the schema and instructions, but not the OAuth credentials or the callback whitelist — you'll still need to redo steps 5 and 6 for your copy.

Can I use my personal Microsoft account to test?

No. The app is registered for work and school accounts only (Microsoft Entra ID). Personal outlook.com, hotmail.com, and live.com accounts aren't accepted.

The server URL in the schema — can I point it elsewhere?

No, leave it as https://moovzyou-onenote-proxy-fwdwo.azurewebsites.net. That proxy is what translates plain JSON into the multipart format Microsoft Graph requires for page creation and updates; calling Graph directly would break those two operations.

Stuck on a step, or need the Client Secret / callback whitelisted? Contact your workspace administrator. Read the Privacy Policy for details on what this app accesses and stores.
